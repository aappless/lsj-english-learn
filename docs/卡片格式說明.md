# 片語卡片格式說明

這份文件說明英文教學系統的「片語／句型／文法／單字卡片」格式。
可以整份交給 Claude、ChatGPT 等 AI，請它照這個格式做卡片；
也可以自己照格式手寫。

---

## 一、怎麼使用（最簡單的方法）

1. 雙擊 `start.bat` 開啟**本機版**，在選單選一個課程
2. 打開畫面下方的「🧩 製作片語卡片」
3. 選範圍（每次 50 句），按 **📋 複製提示詞**
4. 貼到 Claude（claude.ai）或 ChatGPT，送出
5. 把 AI 的回答整段複製，貼回「② 把 AI 的回答放回來」的框框，按 **📥 匯入卡片**
   （也可以把回答存成檔案，按 **📂 從檔案匯入**）
6. 確認卡片沒問題後，用 Git 小幫手「存檔並上傳」，網站就會出現卡片

> 匯入時程式會自動檢查：英文對不上的卡片會被略過，中文對不上的只取消中文高亮。
> AI 的回答前後有說明文字、或用 ```json 包起來都沒關係，程式會自己找出 JSON。

## 二、AI 要回傳的格式

```json
{
  "cards": [
    {
      "i": 12,
      "type": "chunk",
      "match": "let's call it what it is",
      "zhMatch": "說白了",
      "title": "let's call it what it is",
      "meaning": "說白了／直說吧",
      "explain": "要講出一個不太好聽的事實之前，先用這句打預防針，口語很常見。",
      "example": { "en": "Let's call it what it is — a failure.", "zh": "說白了，這就是失敗。" }
    }
  ]
}
```

| 欄位 | 必填 | 說明 |
|---|---|---|
| `i` | ✅ | 句子編號（提示詞裡每句前面的 `[編號]`） |
| `type` | ✅ | 卡片種類，四選一（顏色不同）：<br>`chunk` 詞塊／慣用語（青綠）<br>`pattern` 句型（黃）<br>`grammar` 文法觀念（紫）<br>`word` 單字（藍） |
| `match` | ✅ | 要在英文字幕中高亮的字。**必須一字不差出現在該句英文裡**（大小寫可以不同），否則這張卡片會被略過 |
| `zhMatch` | | 該句中文翻譯裡對應的字，必須一字不差出現在中文裡；找不到就填 `""` |
| `title` | ✅ | 卡片標題。chunk／word 用原字詞；pattern 用公式，例如 `one of the most + adj. + Ns` |
| `meaning` | ✅ | 簡短中文意思，例如「說白了／直說吧」 |
| `explain` | | 一兩句中文說明用法、語氣或常見錯誤 |
| `example` | | 另造的新例句 `{"en": "...", "zh": "..."}`，不要照抄原句 |

## 三、提示詞範本

（本機版的「📋 複製提示詞」會自動填好程度、已教過的內容和句子；
要手動使用的話，把 `{…}` 的地方換掉即可。）

```
你是台灣的英文老師，要把影片逐字稿做成英文教材。
學習者母語是繁體中文（台灣用語），程度：{學習者程度}。

請從下面編號的句子中，挑出「值得教」的重點，做成教學卡片。
- 不是每句都要有；平均每 2～3 句一張即可，寧缺勿濫。
- 優先挑：母語人士常用但課本少教的詞塊、實用句型、容易誤用的文法、有挑戰的單字。
- 不要挑：太基本的字（the, is, good）、專有名詞、和「已教過」重複的內容。

每張卡片的欄位：
- i：句子編號（照下面方括號裡的編號）
- type：chunk（詞塊／慣用語）、pattern（句型，用公式表示）、grammar（文法觀念）、word（單字）四選一
- match：要高亮的英文，必須「一字不差」出現在該句英文中
- zhMatch：該句中文翻譯裡對應的字，必須「一字不差」出現在中文裡；找不到就填 ""
- title：卡片標題。chunk／word 用原字詞；pattern 用公式，例如 "one of the most + adj. + Ns"
- meaning：簡短中文意思
- explain：一兩句中文說明用法、語氣或常見錯誤
- example：另造一個新例句與翻譯 {"en": "...", "zh": "..."}，不要照抄原句

只回傳 JSON，不要任何其他文字，格式：
{"cards":[{"i":0,"type":"chunk","match":"...","zhMatch":"...","title":"...","meaning":"...","explain":"...","example":{"en":"...","zh":"..."}}]}

已教過（不要重複）：{已教過的卡片標題，沒有就寫「無」}

句子：
[0] EN: {英文}
    ZH: {中文}
[1] EN: ...
    ZH: ...
```

## 四、卡片存在課程檔的哪裡

匯入後，卡片會存進 `lessons/影片ID.json` 中對應那一句的 `notes` 陣列
（`i` 欄位不會存進去，因為位置已經代表是哪一句）：

```json
{
  "start": 4.2, "end": 8.0,
  "en": "It's like one of the most complex pieces of hardware on the planet.",
  "zh": "可說是地球上最複雜的硬體之一。",
  "notes": [
    { "type": "chunk", "match": "on the planet", "zhMatch": "地球上", "title": "on the planet",
      "meaning": "全世界、地球上（強調程度）", "explain": "常接在最高級後面加強語氣。",
      "example": { "en": "She's the best chef on the planet.", "zh": "她是全世界最強的主廚。" } }
  ]
}
```

直接手動編輯課程檔也可以，格式對了上傳就會顯示。
